# 💓 AXIOM VOID PULSE

**El detector de pulso emocional y riesgo para cualquier texto.**

Mide la emoción, riesgo de backlash y predicción viral de tweets, prompts, emails, mensajes de Discord, contratos, hilos...

## 🌐 Demo en vivo

[https://axiom-systemstech.github.io/axiom-void-pulse/](https://axiom-systemstech.github.io/axiom-void-pulse/)

## 🎯 ¿Qué hace?

| Métrica | Descripción |
|---------|-------------|
| Pulse Score | 0-100: qué tan "vivo" está el texto |
| Emoción dominante | Alegría, Ira, Tristeza, Miedo... |
| Riesgo backlash | Probabilidad de controversia en X |
| Predicción viral | % de probabilidad de volverse viral |
| Versión potenciada | Texto mejorado para más impacto |
